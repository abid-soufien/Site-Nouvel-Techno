Messages reçus du site

Inscriptions, contacts, demandes de devis et abonnements newsletter envoyés depuis le site public. Stockés dans ce navigateur.

Formations

Champs : id (unique, sans espaces), titre, categorie (ia | dev | cyber | cloud | entreprise), niveau (debutant | intermediaire | avance), duree, format (presentiel | ligne | hybride), prix (« Sur demande » possible), resume, competences (liste), prerequis, certificat, icone (emoji).

Sessions (calendrier)

Champs : id, formationId (doit correspondre à l'id d'une formation), date (AAAA-MM-JJ), horaire, lieu, places.

Formateurs

Champs : id, nom, specialite, experience, bio, initiales (2 lettres). Photo : déposer une image images/equipe/{id}.svg (ou .jpg en adaptant main.js).

Témoignages

Champs : id, nom, role, formation, note (1 à 5), texte.

Articles du blog

Champs : id, titre, categorie (ia | dev | cyber | cloud | entreprise), date (AAAA-MM-JJ), extrait, contenu (paragraphes séparés par une ligne vide). Image : images/blog/{id}.svg.

Paramètres du site

Fichier texte d'administration

Le fichier data/site-content.txt sert de « bloc-notes » d'administration : vous pouvez y préparer le contenu (formations, sessions, articles…) puis le coller ici. Format attendu : JSON identique à celui des éditeurs ci-dessus (clé « formations », « sessions », etc.).
