À QUOI SERT CE FICHIER ?
------------------------
Ce fichier texte est l'un des deux outils d'administration du site :

  1. LA PAGE ADMIN CACHÉE  :  admin.html
     - Non liée depuis aucune page publique (invisible pour les visiteurs).
     - Mot de passe par défaut : nouvel2026
     - Permet de modifier formations, sessions, formateurs, témoignages,
       articles, coordonnées, et de consulter les messages reçus.

  2. CE FICHIER TEXTE  :  data/site-content.txt
     - Sert de « bloc-notes » pour préparer le contenu à la main
       (avec le Bloc-notes Windows, Notepad, VS Code…).
     - Le bloc JSON en bas de fichier peut être collé dans admin.html
       (onglet « Fichier texte » > Importer) pour mettre le site à jour.
     - Vous pouvez aussi éditer directement js/data.js pour rendre les
       changements permanents pour tous les visiteurs.

IMPORTANT — Comment fonctionnent les modifications ?
----------------------------------------------------
- Via admin.html : les changements sont stockés dans le NAVIGATEUR de
  l'ordinateur utilisé (localStorage). Le site les affiche immédiatement
  sur ce navigateur.
- Pour appliquer un changement à TOUS les visiteurs : reporter les mêmes
  valeurs dans js/data.js (ou transmettre le JSON à votre développeur).
